# Daily Note — 13-08-2026

## LoRA-16K decision

- Пользователь выбрал LoRA и 16K completion context из-за проблем с доступным
  hardware и требования к скорости.
- PRIME idea overlays переведены с full-tuning 3K faithful profile на
  `prime_research_16k.yaml`; faithful config сохранён как semantic reference.
- Ordinary GRPO contract исправлен: explicit prompt cap `1024`, vLLM length
  `17408`, LoRA `r=16`, microbatch `1`, accumulation `64`, CPU workers `0`.
- Для PRIME chunks увеличены `256→512`, CPU offload отключён, PRM reference
  batch `2`; это planned speed profile, не measured result.
- Exact tokenizer audit показал: в `grpo_easy_3k` p99 `410`, только `1/3000`
  prompt длиннее 1024; в calibrated PRIME sets outliers `>1024` отсутствуют.
- Решение: оставить prompt cap `1024`, единичный outlier отфильтровать.
- Аналитический VRAM estimate: `23–27 GiB`, conservative envelope до
  `30–32 GiB`; обязательна проверка one-update GPU smoke.
